One insight: what will go wrong before the next deadline, who can stop it this week, and how we know.

CPipeline

Four stage folders, run in order. Each run writes its files to runs/<project>@<today>/, so you can tell a run's progress by which files exist. A person reads each output before the next stage runs.

StageWho does the workWritesHuman check
01 ingestCode. Turns .docx, .txt, .xlsx and .pdf into located lines with a doc date and author.01_docs.jsonlEvery file appears once, and its date looks right.
02 extractAI Reads one doc at a time and emits typed claims, each with a quote that must match the source word for word.02_claims.jsonlMain gate. Read the claims and fix wrong ones by hand.
03 reconcileCode. Resolves dates, merges claims into items, runs the detectors, scores the results.03_findings.jsonCompare against the golden file. Fix the code, never the output.
04 briefAI writes the sentences; code checks them and copies in every number. Renders the board.04_board.htmlRead each card aloud. Would the named person be OK seeing it?

FRules the tool follows

Always

  • Code computes every date and count. The AI reads, connects, and explains.
  • Every sentence on the board has a receipt. If it can't be traced to a file and a quote, it doesn't ship.
  • Lead with the task, then the person: "Demo request → Tyler, by Thu Oct 22".
  • Show constraints without reasons: "away Oct 28 to Nov 1", with no mention of why.
  • Show a confidence level and a one-line reason on every card.
  • Tag cards about a person's load or availability "talk first".

Never

  • Rank or score people, or count anyone's absences or late items.
  • Guess at motive or effort.
  • Suggest going to the instructor about a teammate. The brief and the charter both say to talk as a team first.
  • Draft or hint at peer evaluation content. Those go only to the instructor.
  • Send someone's real project data to a cloud model without their permission.
  • Use red. On a team-facing tool it reads as blame. Amber means "act this week".

IFallbacks and limits

If something breaks

  • Extraction is flaky: fix 02_claims.jsonl by hand and say so in the demo. That is the human check doing its job.
  • The UI is late: render 04_brief.json as markdown.
  • The API is down: replay the cached runs.

What we say out loud

  • It only knows what's written down. It can't see the group chat, email, or Figma.
  • Extraction from messy notes is imperfect. That's why claims are editable and confidence is shown.
  • It can start a conversation about workload. It can't tell how anyone feels.
